    Existence and uniqueness of solutions

    Just because we can write down an initial value problem, doesn't necessarily mean that there is a solution. And if there is a solution, it doesn't necessarily mean that there is only one solution.

    From a practical point of view: If your initial value problem does not have exactly one solution, you probably did the modeling incorrectly.

  • If there is no solution, then what exactly are you looking for?
  • Mathematical models are usually used to predict the future (e.g., where will the ball land?), so if there is more than one solution, that is usually a bad sign.
